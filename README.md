# Hello World Modern Web Page

## Brief Description
This project is a simple, modern web application designed to display "Hello World" on the screen. It includes a button that, when clicked, changes the text color, showcasing dynamic interaction within web pages. This application serves as a foundation for understanding basic web development concepts including HTML, CSS, and JavaScript.

## Features
- **Display Message:** Shows "Hello World" text on the webpage.
- **Interactive Button:** A button that changes the color of the "Hello World" text when clicked.
